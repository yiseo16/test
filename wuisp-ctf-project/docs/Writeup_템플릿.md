# Write-up 템플릿

```markdown
## 챌린지명

### 취약점 설명
어떤 취약점인지, 왜 발생했는지

### 의도된 풀이
단계별 공격 방법 (스크린샷 포함)

### 왜 위험한가
실제 서비스에서 이 취약점이 뚫리면 어떤 피해가 있는지

### 방어 방법
안전하게 고치려면 어떻게 해야 하는지 (Before/After 코드)
```

## 작성 팁
- 스크린샷은 "Before(공격 성공)" / "After(패치 후 막힘)" 형태로 남겨두면 나중에 포트폴리오에 쓰기 좋습니다.
- 방어 방법은 실제로 코드까지 고쳐볼 필요는 없고, "이렇게 고치면 된다"는 코드 스니펫만 있어도 충분합니다.
