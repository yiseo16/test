# AWS 운영 경계

실제로 다른 사람들에게 CTF를 오픈하는 만큼, 아래 원칙은 예외 없이 지킵니다.

## 넣지 말아야 할 것
- 실제 개인정보 (진짜 이름, 전화번호, 이메일 등)를 더미 데이터로 쓰지 않기
- 실제로 쓰는 개인 쿠키/세션 값 재사용하지 않기
- AWS Access Key, Secret Key 등 자격 증명을 코드나 Docker 이미지, GitHub 저장소에 절대 포함하지 않기 (`.env` 사용, `.gitignore`로 제외)
- 리더보드나 챌린지 안에 운영자 계정, 실제 비밀번호, 실제 서비스에서 쓰는 값 넣지 않기

## 운영 기간
- 공개 기간은 짧게 정합니다 (예: 3~7일). 기간을 정하고 공지에 명시합니다.
- 종료 시각을 미리 못 박아두고, 그 시점에 맞춰 아래 정리를 진행합니다.

## 종료 후 정리
아래 항목을 정리할 **담당자를 미리 지정**해두세요 (보통 4조).

- [ ] EC2 인스턴스 종료(Terminate) 또는 중지(Stop)
- [ ] 보안 그룹에서 열어둔 포트 재확인 및 정리
- [ ] Docker 볼륨(리더보드 DB 등) 백업 필요 여부 확인 후 정리
- [ ] 사용한 AWS 키 폐기/로테이션 (프리티어라도 습관적으로)

## 참고
이 모든 원칙은 "포트폴리오/스터디 목적의 학습용 CTF"라는 성격을 지키기 위한 최소한의 안전장치입니다. 실제 서비스 운영 수준의 보안까지는 필요 없지만, 위 항목만은 예외 없이 지켜주세요.
